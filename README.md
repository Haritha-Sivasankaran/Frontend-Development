## 📖 Curriculum Overview

The **30-Day Frontend Development Curriculum** by **Ednue Technologies** is an industry-aligned, project-driven learning journey. Designed for aspiring software engineers and full-stack developers, every single module is structured into a **60-minute time-boxed lesson** featuring:
- **Core Theoretical Concepts & Architectural Mental Models**
- **Real-World Engineering Scenarios**
- **Complete, Runnable Mini Projects with Zero TODOs or Placeholders**
- **Dual Execution**: Instant browser execution (open `index.html`) AND modern development server workflows (Vite / Node.js)
- **Concept Mappings, Common Pitfalls, Student Challenges, and Technical Interview Questions**

## 🏆 Capstone Showcase: Day 30 — Ednue LMS

The capstone application ([`day-30-capstone-lms`](./day-30-capstone-lms)) combines the entire curriculum into an enterprise-grade Learning Management System featuring:

1. **Catalog & Search**: Multi-field search across titles, mentors, topics, and technology tags.
2. **Category Filtering**: Filter across 6 technical tracks (*Web Development*, *Cloud & DevOps*, *Data Science & AI*, *UI/UX Design*, *Mobile Development*, *Cyber Security*).
3. **Interactive Syllabus**: Real-time checklist where students check off completed lessons, automatically recalculating course progress from 0% to 100%.
4. **Verified Certificates**: Automated credential generation upon reaching 100% course completion, showcaseable in the learner profile.
5. **Student Dashboard**: Real-time progress trackers, enrollment metrics, and unenrollment controls.
6. **Controlled Registration Form**: Real-time regex pattern validation, boundary checks, and `touched` state tracking.
7. **User Profile**: Editable learner avatar, bio, career goals, and technical skills cloud.
8. **Asynchronous REST Service**: Typed API service with network latency simulation and error handling.
9. **Responsive Design**: Mobile drawer navigation and responsive layouts supporting mobile, tablet, and desktop viewports.
10. **100% TypeScript Compile-Time Safety**: Strict typing for domain models, component props, and API envelopes.

## 🚀 How to Run Any Project

### Method 1: Instant Browser Execution (Zero Setup)
Every project includes an `index.html` file configured for standalone execution.  
Simply double-click `index.html` in any browser or right-click and select **"Open with Live Server"** in VS Code.

### Method 2: Modern Bundler Execution (Vite / Node.js)
Projects from Days 24–30 include `package.json` configurations. Run them via terminal:

```bash
# 1. Navigate into any project folder
cd day-30-capstone-lms

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open `http://localhost:3000` to view the running application.
