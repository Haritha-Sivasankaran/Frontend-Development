Block Scope

Block Scope: 'var' vs. 'let'

Code blocks { ... } isolate let & const, but var leaks outside!

if (true) {
    var leakedVar = "I am var";
    let trappedLet = "I am let";
}
// Access outside block:
console.log(leakedVar);  // Works!
console.log(trappedLet); // ReferenceError!

2. Variable Hoisting & Temporal Dead Zone (TDZ)

Variable Hoisting

Hoisting with 'var'

'var' declarations are hoisted and initialized to undefined before line execution.

console.log(hoistedItem); // undefined
var hoistedItem = "Laptop Pro";
console.log(hoistedItem); // "Laptop Pro"

Temporal Dead Zone

Hoisting with 'let' (TDZ)

'let' & 'const' are hoisted into the Temporal Dead Zone without initialization.

// Accessing before declaration line throws:

let tdzItem = "Mechanical Keyboard";

3. Function Hoisting (Declaration vs Expression)

Function Hoisting

Function Declaration Hoisting

Function declarations are fully hoisted with their implementation and can be called anywhere.

// Invoking function BEFORE definition:
const discount = getDiscount(150); // Works!

function getDiscount(price) {
    return price * 0.15;
}

Function Expression

Function Expression Hoisting

Function expressions stored in const / let variables stay in TDZ until assigned.

// Invoking variable before assignment:
const tax = calculateTax(100); 

const calculateTax = function(amt) {
    return amt * 0.08;
};
