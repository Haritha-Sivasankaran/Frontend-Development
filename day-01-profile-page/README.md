# Day 1: HTML Introduction and Structure

## Mini Project: Personal Profile Webpage

A foundational project designed to teach semantic HTML document structure without CSS or JavaScript.

---

### Learning Objectives
- Write a valid HTML5 boilerplate document from scratch.
- Understand the role and behavior of `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`.
- Configure page metadata: `charset="UTF-8"`, viewport settings, and `<title>`.
- Use heading hierarchy correctly (`<h1>` through `<h6>`).
- Organize content using text elements (`<p>`, `<strong>`, `<em>`, `<hr>`), images (`<img>`), and lists (`<ol>`, `<ul>`, `<li>`).

---

---

### How to Run
1. Open this folder in your code editor (e.g., VS Code).
2. Right-click `index.html` and select **"Open with Live Server"** or double-click `index.html` to open it directly in your browser.

---

### Student Challenges
1. **Hyperlink Addition**: Add a hyperlink (`<a>`) to the header that links to your GitHub or LinkedIn profile using the `target="_blank"` attribute.
2. **Blockquote Addition**: Add a new section titled "Favorite Quote" using the `<blockquote>` element, wrapping the quote inside it and citing the author with `<cite>`.
3. **Nested List Modification**: Inside the "Education" section, nest an unordered list (`<ul>`) under your college entry listing two major coursework subjects or achievements.
